# Game Designer Portfolio

이 프로젝트는 게임 기획자로서의 사고 과정, 시스템 설계 능력, 콘텐츠 기획 능력을 구조적으로 보여주기 위한 인터랙티브 포트폴리오 시스템이다.

단순한 이력서나 정적 페이지가 아니라, **하나의 제품(Product)으로 설계된 포트폴리오 플랫폼**이다.

---

## 1. 프로젝트 목적

이 포트폴리오는 다음을 목표로 한다:

- 게임 기획자로서의 역량을 구조적으로 증명
- 시스템/콘텐츠 기획 능력 구분하여 표현
- 분석 및 문제 해결 능력 시각화
- 실제 서비스 수준의 포트폴리오 제공

---

## 2. 핵심 특징

### 📌 데이터 기반 구조

모든 콘텐츠는 JSON 기반 데이터로 관리된다.

- projects.json
- analysis.json
- skills.json
- resume.json

UI는 이 데이터를 시각적으로 표현하는 역할만 수행한다.

---

### 📌 문서 중심 개발

이 프로젝트는 코드보다 문서를 우선한다.

- PROJECT.md → 프로젝트 목표
- ARCHITECTURE.md → 시스템 구조
- DATA_MODEL.md → 데이터 설계
- DESIGN_SYSTEM.md → UI/UX 원칙
- CLAUDE.md → 개발 규칙

---

### 📌 제품으로서의 포트폴리오

이 프로젝트는 단순한 웹사이트가 아니라 다음과 같은 제품으로 설계된다:

- 사용자 경험 중심 구조
- 빠른 정보 탐색
- 직관적인 프로젝트 이해
- PDF 기반 상세 문서 제공
